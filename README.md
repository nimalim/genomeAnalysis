# Genome Analysis of Niphotrichum japonicum: Assembly and Heat-Stress Gene Expression
This project builds and annotates a genome assembly for the moss Niphotrichum japonicum and compares gene expression between heat-stressed and control samples. The aim is to find genes that respond to high temperature and so help explain how this moss copes with heat.

Note The sequencing data come from the study by Zhou et al. (2023) listed below.

Reference
Zhou, X., Peng, T., Zeng, Y., Cai, Y., Zuo, Q., Zhang, L., Dong, S., & Liu, Y. (2023). Chromosome-level genome assembly of Niphotrichum japonicum provides new insights into heat stress responses in mosses. Frontiers in Plant Science, 14, 1271357. https://doi.org/10.3389/fpls.2023.1271357
